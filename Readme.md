# DevOps Tutorial Notes

Notes and reference code examples from DevOps learning resources, official guides, and tutorials.

## Overview

A structured collection of hands-on exercises and summaries covering core DevOps tooling: containerization, CI/CD pipelines, container orchestration, and cloud infrastructure as code.

## Topics Covered

| Topic | Source / Reference | Description |
|-------|--------------------|-------------|
| Docker Fundamentals | Docker Official Docs | Images, containers, networks, volumes, multi-stage builds |
| GitHub Actions | GitHub Documentation | Automated workflows, CI test runners, deployment triggers |
| Kubernetes Basics | Kubernetes.io Tutorials | Pods, Deployments, Services, ConfigMaps, and Namespaces |
| Terraform Intro | HashiCorp Learn | Infrastructure as Code syntax, state management, provider blocks |

## How to Use

Each directory contains focused notes and reproducible code snippets:
- `notes.md` -- Key takeaways and architectural decisions
- Working configuration files and sample manifests
- Practical debugging tips and common pitfalls
